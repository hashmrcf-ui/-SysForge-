# دليل المصادر المفتوحة — لأنظمة الأعمال

## كيف تستخدم هذا الملف

في PHASE 3 (SCOUT)، اقرأ القسم المناسب لنوع النظام المطلوب.
عرض أفضل 3 خيارات على المتدرب بالأسلوب الموضح في كل قسم.

---

## 📊 نظام المحاسبة والفواتير

### الخيار 1 — Akaunting ⭐ الأنسب للمبتدئ
**ما هو:** نظام محاسبة ويب مفتوح المصدر — Laravel في الخلفية، Vue في الواجهة
**ما يحتويه جاهزاً:** فواتير، مصروفات، تقارير مالية، متعدد العملات، لوحة تحكم
**ما ينقصه:** لا يوجد وكيل AI، التخصيص محدود في النسخة المجانية
**رابط:** https://akaunting.com | https://github.com/akaunting/akaunting
**طريقة الاستخدام:**
```bash
git clone https://github.com/akaunting/akaunting.git
composer install
php artisan key:generate
# ثم إضافة وكيل AI فوقه
```
**الاستراتيجية المقترحة:** ابنِ فوقه — أضف AI endpoint منفصل يقرأ من نفس قاعدة البيانات

---

### الخيار 2 — Invoice Ninja
**ما هو:** نظام فواتير احترافي — Flutter للموبايل، Laravel للخادم
**ما يحتويه جاهزاً:** فواتير، عروض أسعار، بوابات دفع، عملاء، تقارير
**ما ينقصه:** ليس نظام محاسبة كامل (لا يوجد أستاذ عام)
**رابط:** https://github.com/invoiceninja/invoiceninja
**الاستراتيجية المقترحة:** مناسب لو الهدف الفواتير فقط — ليس محاسبة شاملة

---

### الخيار 3 — ERPNext (Frappe)
**ما هو:** نظام ERP كامل — Python/Frappe framework
**ما يحتويه جاهزاً:** محاسبة كاملة + مبيعات + مشتريات + HR + مخزون
**ما ينقصه:** معقد جداً، منحنى تعلّم عالٍ
**رابط:** https://github.com/frappe/erpnext
**الاستراتيجية المقترحة:** مرجع للتعلم فقط — لا تبنِ فوقه إذا كنت مبتدئاً

---

### 🎯 توصية المحاسبة
```
مبتدئ يريد الشحن بسرعة    → Akaunting + إضافة AI
مبتدئ يريد التعلم          → ابنِ من الصفر بـ Next.js (Option A)
محترف يريد ERP كامل        → ERPNext أو Frappe
```

## 🏥 نظام المستشفى والعيادة

### الخيار 1 — Bahmni ⭐ الأشمل
**ما هو:** نظام مستشفى مكتمل — OpenMRS + Odoo + Dcm4Chee
**ما يحتويه جاهزاً:** سجلات طبية، مواعيد، صيدلية، تصوير طبي، فواتير
**ما ينقصه:** ثقيل جداً، يحتاج سيرفر قوي، تعقيد عالٍ
**رابط:** https://bahmni.org | https://github.com/Bahmni

---

### الخيار 2 — OpenEMR
**ما هو:** أشهر نظام EMR مفتوح — PHP
**ما يحتويه جاهزاً:** سجلات مرضى، مواعيد، وصفات، تقارير، تأمين
**ما ينقصه:** واجهة قديمة، يحتاج تخصيص كبير للعربية
**رابط:** https://github.com/openemr/openemr

---

### الخيار 3 — بناء مخصص بسيط (عيادة صغيرة)
**ما هو:** نظام Next.js + FastAPI بسيط من الصفر
**المناسب لـ:** عيادة صغيرة (1-3 أطباء)، موعد + ملف مريض + وصفة
**الوقت:** 6-8 جلسات بدون إعادة اختراع عجلة كبيرة

---

### 🎯 توصية المستشفى
```
مستشفى كبير (50+ طبيب)    → Bahmni أو OpenEMR + تخصيص
عيادة متوسطة (5-20 طبيب)  → OpenEMR مع تخصيص عربي
عيادة صغيرة (1-5 أطباء)   → ابنِ من الصفر (Option A/B)
```
