# بلوبرينت — نظام المستشفى والعيادة

## نظرة عامة
نظام إدارة طبية يشمل المرضى، المواعيد، السجلات الطبية، الصيدلية، والفواتير — مع وكيل AI للمساعدة السريرية.

---

## الوحدات الأساسية

### 1. إدارة المرضى
**ما تحتويه:**
- ملف المريض الكامل (بيانات شخصية + تاريخ طبي)
- رقم ملف فريد لكل مريض
- الحساسيات والأمراض المزمنة

**جداول DB:**
```sql
patients (id, file_number, name, dob, gender, phone, address, blood_type)
patient_history (id, patient_id, condition, notes, date)
allergies (id, patient_id, allergen, severity)
```

---

### 2. المواعيد والجدول الزمني
**ما تحتويه:**
- حجز المواعيد (يدوي + أون لاين)
- جدول الطبيب اليومي
- تأكيد + تذكير تلقائي

**جداول DB:**
```sql
doctors (id, name, specialty, license, working_hours)
appointments (id, patient_id, doctor_id, date, time, status, type, notes)
```

**صفحات Next.js:**
- `/appointments` — التقويم اليومي
- `/appointments/new` — حجز موعد جديد
- `/doctors/[id]/schedule` — جدول الطبيب

---

### 3. السجلات الطبية والوصفات
**ما تحتويه:**
- تدوين نتيجة الكشف
- الوصفة الطبية
- طلبات التحاليل والأشعة
- تحميل نتائج التحاليل

**جداول DB:**
```sql
medical_records (id, appointment_id, diagnosis, notes, created_by)
prescriptions (id, record_id, medications, instructions)
lab_requests (id, record_id, test_name, status, result_url)
```

---

### 4. الصيدلية والأدوية
**ما تحتويه:**
- مخزون الأدوية
- صرف الوصفات
- تنبيه انتهاء الصلاحية

---

### 5. الفوترة والمدفوعات
**ما تحتويه:**
- فاتورة الكشف + الخدمات
- التأمين الصحي
- كشف الحساب للمريض

---

### 6. وكيل AI — المساعد الطبي

**مهامه:**
- "ما مواعيد الدكتور أحمد غداً؟"
- تنبيه: "المريض X لديه حساسية من البنسلين"
- اقتراح مواعيد بناءً على الكثافة
- تلخيص التاريخ الطبي للمريض قبل الكشف
- إحصائيات: أكثر الأمراض تشخيصاً هذا الشهر

---

## ترتيب البناء

```
1. هيكل + DB
2. المرضى (ملفات + بحث)
3. الأطباء والجدول
4. المواعيد
5. السجلات الطبية + الوصفات
6. الصيدلية
7. الفوترة
8. وكيل AI
9. الصلاحيات (طبيب / ممرضة / إداري / محاسب)
```
